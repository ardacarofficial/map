Harita is a live, human-reviewed map editor. Start with get_session and get_editor_context; inspect actual art before painting. Read MCP resource harita://guide/overview (resources/list and resources/read) for a short authoring entry point, then load only needed sections: planning, assets, painting, collaboration, validation, editor or workflow. harita://guide/skill is the portable skill. Prefer meaningful names and reusable semantic layers; adapt structure to the task. Tool schemas define current arguments, limits and capabilities. Exclusive edits use begin_edit → document tools (context optional) → finish_edit; keep begin_edit's resumeToken and call resume_edit after a disconnect or to amend submitted work, nothing is rolled back on disconnect; shared region drafts also use join_edit and explicit per-member ownership/revisions. After uncertain outcomes inspect session state. Preview and validate before submitting. Only the human approves the common draft; agents cannot save/export documents or discard peers' contributions. UI setters remain independent of document review.
