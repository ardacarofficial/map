# blob47-32.png

32px tiles, 8 columns x 6 rows (256x192), row-major, 47 tiles (indices 0-46); slots 47 is empty/transparent.
Terrain: grass (A) over dirt. A neighbour bit set = neighbour cell is also grass.

Bitmask (cr31 convention): N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128.
Reduction rule: a corner bit counts only if BOTH adjacent edge bits are set (e.g. NE kept only if N and E set). This yields exactly 47 unique masks.
Layout: tiles are the 47 reduced masks sorted ascending by value; tile index = rank. Lookup: reduce(mask) -> index via table below.
NOTE: this is a self-consistent ascending layout, NOT the cr31 7x7 picture arrangement.
Visual: grass fills the tile centre; a dirt border 8px wide appears on each side whose edge bit is clear; for each corner whose edges are both set but corner bit clear, an 8x8 dirt notch appears at that corner.
