# wang16-32.png

32px tiles, 4 columns x 4 rows (128x128), row-major, index = col + row*4 (0-15).
Index = sum of corner bits: NE=1, SE=2, SW=4, NW=8. A set bit means that tile corner is grass (else dirt).
Rendering: each 16x16 quadrant is grass if its corner bit is set, else dirt. Tile 0 = all dirt, tile 15 = all grass.
Adjacent tiles must agree on shared corners (e.g. tile's NE corner == right neighbour's NW corner).
